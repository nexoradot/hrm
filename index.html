Privileged access policy

  • Use individual named admin accounts; no shared logins
  • Require MFA and least-privilege role assignment
  • Bootstrap the first platform admin through a trusted server-side process
  • Never expose a service-role key in browser JavaScript
  • Log privileged actions server-side and restrict log mutation
  • Test cross-tenant access using independent test accounts
The browser interface is not an authorization boundary. Database policies and trusted server functions must enforce every privileged action.
